# FB-Anrufmonitor – Downloads

Anrufmonitor für die AVM Fritz!Box (Windows) – Anrufanzeige, vollständige Anrufliste, Kontakte aus der Fritz!Box,
Rückwärtssuche, Notizen und Wählen übers Festnetz (auch per Rufnummern-Link oder Strg+Alt+W aus jedem Programm).

## Download und Installation

1. Aktuelle Version unter **[Releases](../../releases/latest)** herunterladen (`FB-Anrufmonitor-Setup-x.y.z.exe`).
2. Setup ausführen – wahlweise nur für mich (ohne Admin-Rechte) oder für alle Benutzer; die .NET-Laufzeit ist enthalten.
3. Einmalig den Callmonitor der Fritz!Box aktivieren: an einem angeschlossenen Telefon `#96*5*` wählen.
4. Beim ersten Start die Fritz!Box-Daten in den Einstellungen eintragen.

**Voraussetzungen:** Windows 10 (1809) oder Windows 11, 64 Bit; AVM Fritz!Box.

Installierte Versionen prüfen regelmäßig auf Updates und aktualisieren sich per Klick.
Jedes Setup liegt mit SHA-256-Prüfsumme (`.sha256`) bei; die App prüft sie vor jedem Update.

**Hinweis:** Das Setup ist noch nicht digital signiert. Bei aktivem Windows Smart App Control kann es blockiert werden.

Dieses Repository enthält ausschließlich die Installationsdateien.
